# Minimal Work

Execute tarefas de código de forma objetiva, com o menor contexto e a menor quantidade de alterações necessárias.

## Regras
- Não leia o projeto inteiro sem necessidade.
- Comece pelos arquivos diretamente relacionados à tarefa.
- Reutilize código existente antes de criar algo novo.
- Faça o menor número de alterações possível.
- Não faça refatorações ou melhorias que não foram solicitadas.
- Ao terminar, pare.
